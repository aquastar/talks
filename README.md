# AI Literacy for CS Faculty

A ~25-minute AI literacy talk for the Fall 2026 CS faculty meeting, built with reveal.js. Two parts. **How it works** goes from next-token prediction up to agents: the nested circles of "AI", a click-through timeline from 2012 to 2026, what "GPT" stands for, tokenization, next-token sampling, the hidden chat template, how a chatbot is trained (pretraining, SFT, RLHF), chain of thought and RLVR-trained reasoning models, tool calls in one text window, the agent loop, RAG, MCP, workflows vs. agents, steering agents with markdown files, and a real-world agent session. **Pace of change** covers METR time horizons, context and cost, the jagged frontier, open weights and open harnesses, and six trends to watch. It builds on the AI Committee's *AI Literacy Tutorial* draft.

`glossary.md` is a one-page handout of the terms used in the talk.

Play online: https://aquastar.github.io/ai-literacy-faculty/

Keys: Space or arrows to advance, S for speaker notes (with timing cues), Esc for overview.
